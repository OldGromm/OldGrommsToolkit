1.0

- Initial Release

________________________________________________

1.1

- Added profile support (each options category can use either an account-wide setup or each individual character's setup)

- Added hearthstone macro.

________________________________________________

1.2

- Fixed the special mount icon not disappearing after resetting the list

- Fixed an error when adding an aquatic mount to the list while there was no flying mount present.

________________________________________________

1.3

- Added an option to only display the combat lockdown message once per error type or hide it completely.
  This setting works independently from the other add-on messages its and its display settings.

- The add-on will now only update the list order when dismounting, and edit the macro when mounting up.
  This should fix the constant combat lockdown messages when dismounting and simultaneously getting into combat.

________________________________________________

1.4

- Added an option to hide the talking head frame.
  You can define how many times each message should play before they're being hidden.
  Disable the talking head feature of other add-ons to prevent overlaps.

- Fixed an error caused byselecting "No Music" for the victory sound feature if no other music track was being previewed before.

________________________________________________

1.5

- Added "Tidebound Grotto" to the list of instances to check for the Repair Message feature.

- Added "Hearthkeeper's Wandering Caravan" to the list of special mounts for the Mount Macro feature.

- Added "Personal Key to the Arcantina" as a special option for the hearthstone macro.

- The talking head frame can now be hidden depending on the instance type (dungeons, raid, PvP).
  Additionally, it can also be hidden during mythic+ runs-only (the dungeon option will hide it in both regular and m+ scenarios).
